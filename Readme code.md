پروژه سیستم مهارت‌جویی مطابق با نیازمندی‌های بازار کار
=
شرح پروژه
-
در این پروژه با وارد کردن رزومه به‌صورت متن یا PDF، سه مورد از مطابق‌ترین عناوین شغلی با رزومه فرد ارائه می‌شود. همچنین تحلیلی از حداقل تجربه کاری ذکرشده در آگهی‌های شغلی، میزان تقاضا برای آقا یا خانم، و بازه حداقل و حداکثر حقوق در مرتبط‌ترین شغل با رزومه کاربر نمایش داده می‌شود.  
خلاصه‌ای از شرح شغل و نقشه‌ راهی برای یادگیری مهارت‌هایی که در رزومه کاربر وجود ندارند نیز پیشنهاد می‌گردد.  
در پایان، کاربر می‌تواند از طریق چت با هوش مصنوعی، پرسش‌های خود را مطرح کند.

ساختار پوشه‌ها و فایل‌ها
-
در ادامه، توضیحاتی درباره هر پوشه و فایل ارائه شده است:  
- **پوشه API**: شامل ۴ فایل مربوط به اتصال به API برای انجام وظایف مشخص.  
  - **فایل chat.py**: برای ارتباط کاربر با چت‌بات. تابع `chat_with_chatbot` پرامپت کاربر را دریافت کرده و پاسخ چت‌بات را بازمی‌گرداند.  
  - **فایل roadmap.py**: برای تولید نقشه‌ راه متناسب با عنوان شغلی و مهارت‌های غایب در رزومه.  
  - **فایل skills_process.py**: برای تبدیل مهارت‌های موردنیاز در شغل پیشنهادی به قالب یک مجموعه پایتونی از طریق پرامپت به چت‌بات.  
  - **فایل summarization.py**: برای تولید خلاصه‌ای از تمامی شرح‌های مرتبط با یک موقعیت شغلی.  
- **پوشه data**: شامل دو دیتاست مورد استفاده در پروژه.  
- **پوشه source_code**: شامل کلیه توابع مورد استفاده در فایل app.py.
  - **فایل init__.py__**: برای تشخیص پوشه به عنوان پکیج.
  - **فایل inference.py**: شامل دو تابع برای پیش‌بینی سه موقعیت شغلی نزدیک و نزدیک‌ترین موقعیت به رزومه.  
  - **فایل plot.py**: شامل توابع نمایش نمودارهای آماری، و همچنین توابع استخراج حداقل و حداکثر حقوق و سابقه کاری.  
  - **فایل preprocessing.py**: شامل توابع پیش‌پردازش متون برای آماده‌سازی جهت پردازش.  
  - **فایل semantic_matching.py**: تابع `find_most_similar_job_titles` برای یافتن عنوان‌های شغلی مشابه در دیتاست دوم با استفاده از شباهت معنایی.  
  - **فایل train_model.py**: آموزش مدل بر اساس الگوریتم Naive Bayes و بردار TF-IDF. مدل نهایی در مسیر `models` ذخیره می‌شود.  
- **فایل app.py**: رابط گرافیکی پروژه با استفاده از Streamlit. اسکریپت‌های موجود در پوشه `source_code` در این فایل استفاده شده‌اند. همچنین مدیریت خطاهای احتمالی در زمان اجرا انجام شده است.  
- **فایل requirements.txt**: شامل پکیج‌های موردنیاز پروژه.
